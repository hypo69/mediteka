# core

## Описание
Корневой модуль плагина media_organizer. Содержит основные компоненты для организации и управления медиатекой:
- Управление базой данных SQLite (media_database.py)
- Сканирование медиафайлов (media_scanner.py)
- Классификация медиа через TMDB и Gemini (genre_classifier.py, media_organizer.py)
- RAG-индексация для семантического поиска (media_rag.py)
- Аудит целостности медиатеки (media_auditor.py)
- Генерация отчётов (report_generator.py)

## Обзор файлов и модулей

### Основные модули
* `media_database.py` — Управление SQLite-базой данных медиатеки. Хранение записей о фильмах, сериалах, эпизодах и дубликатах.
* `media_organizer.py` — Главный плагин для сканирования и классификации медиатеки через TMDB и Gemini.
* `media_scanner.py` — Базовое сканирование медиафайлов: извлечение названий, сезонов, размеров.
* `genre_classifier.py` — Классификатор медиа по жанрам с использованием TMDB API и Gemini.
* `media_rag.py` — Построение RAG-индекса из записей медиатеки для семантического поиска.
* `media_auditor.py` — Аудит медиатеки: сверка данных БД с физическим наличием файлов и состоянием торрентов.

### Вспомогательные модули
* `media_tools.py` — Инструменты для обработки медиа-данных и dispatch вызовов инструментов.
* `report_generator.py` — Генератор отчётов для отдельных медиа-записей.
* `series_collector.py` — Сборщик информации о сериалах.
* `media_tracker.py` — Отслеживание медиафайлов.
* `media_rebuild.py` — Инструменты для восстановления/перестройки БД.

## Связи и зависимости
* Использует TMDB API для получения информации о медиафайлах
* Интегрируется с Gemini для обогащения метаданных
* Использует qBittorrent для управления торрентами
* Создаёт отчёты в форматах JSON и Markdown
