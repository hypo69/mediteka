# Модуль `plugins/media_organizer/reports` — Отчеты и дампы медиатеки

## Назначение
Директория предназначена для хранения автоматически генерируемых отчетов, CSV-выгрузок и аналитических дампов:
- `all_media_data.csv`: полный экспорт базы медиатеки.
- `audit_results.json`, `audit_discrepancy_report.md`: отчеты аудитов дисков и расхождений.
- `potential_duplicates.csv`, `actionable_deletions.csv`: отчеты по обнаруженным дубликатам.
- `inferred_titles_report.csv`: отчет о сопоставлении названий тайтлов.\n
