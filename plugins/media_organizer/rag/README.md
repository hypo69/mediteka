# RAG Системы Медиатеки

## Предназначение
Данный модуль реализует систему RAG (Retrieval-Augmented Generation) для поиска и извлечения информации о фильмах из локальной базы данных `media.db`. Он позволяет выполнять семантический поиск по сюжету, настроению, актерам и другим метаданным.

## Принцип работы
1. **Индексатор (`indexer.py`)**: Извлекает записи из таблицы `media` (SQLite), формирует текстовые документы, обогащенные метаданными, и создает их векторные представления (эмбеддинги) с использованием локальной модели (например, `sentence-transformers`).
2. **Векторная база данных**: Используется легковесная БД `ChromaDB` для хранения и быстрого поиска векторов.
3. **Модуль поиска (`search.py`)**: Принимает естественный текстовый запрос, векторизует его и возвращает список наиболее релевантных фильмов из фильмотеки с их данными.

Модуль спроектирован так, чтобы работать локально, без жестко закодированных путей.
