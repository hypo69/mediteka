# Модуль `plugins.rag` — Семантический RAG-поиск

## Назначение
Плагин обеспечивает семантический поиск по медиатеке и базе знаний для AI-ассистента:
- `__init__.py`: реализация плагина `RagPlugin`, перехват запросов поиска фильмов и рекомендаций.
- `tools/`: инструменты перестроения индексов, векторизации и управления базой знаний.
- `reports/`: текстовые дампы и отчеты очистки RAG данных.\n
