# Модуль `plugins/rag/tools` — Инструменты управления RAG и базой знаний

## Назначение
Скрипты обслуживания векторных индексов и базы знаний:
- `manage_knowledge.py`: CLI для извлечения, добавления и инициализации реестра знаний.
- `rebuild_chat_rag.py`: полное перестроение RAG-индекса для чат-ассистента.
- `reindex_rag.py`: обновление векторных эмбеддингов.
- `validate_rag_files.py`: проверка корректности файлов базы знаний.
- `inspect_user_rags.py`: инспекция персональных RAG-индексов пользователей.\n
