# Модуль `plugins/qbittorrent/tools` — Утилиты управления торрентами

## Назначение
Консольные инструменты для синхронизации и обслуживания торрентов:
- `assign_categories_to_torrents.py`: автоматическое назначение категорий в qBittorrent по метаданным медиатеки.
- `assign_torrents_ids.py`: сопоставление хэшей торрентов с ID тайтлов в `media.db`.
- `update_torrent_state.py`: актуализация статусов раздачи и прогресса скачивания.
- `update_torrents_path.py`: синхронизация путей сохранения файлов.
- `clear_torrents_meta.py`: очистка устаревших метаданных.
- `orchestrator_torrent.py`: автоматическая оркестрация загрузок и раздач.\n
