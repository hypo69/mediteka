# Модуль `plugins` — Плагинная архитектура

## Назначение
Каталог содержит подключаемые функциональные плагины системы `mediteka`.
Каждый плагин наследует базовый класс `BasePlugin` (`plugin.py`) и экспортирует точку входа `plugin(ai_model)`.
Функция `load_plugins(ai_model)` в `__init__.py` динамически сканирует и регистрирует активные плагины.

## Доступные плагины
1. `media_organizer`: управление медиатекой, сканирование дисков, разметка метаданных и RAG.
2. `qbittorrent`: интеграция с торрент-клиентом qBittorrent.
3. `rag`: семантический поиск по медиатеке для чат-ассистента.
4. `media_layer`: облегченный слой доступа к базе медиа.
5. `torrent_playwright`: поиск и фильтрация торрентов через Playwright (Rutracker, NNMClub).
6. `web_search`: веб-поиск через Playwright с суммаризацией через AI.
7. `movie_search_sources`: каталог стриминговых сервисов и онлайн-кинотеатров.
8. `telegram_bot`: удаленное управление через Telegram Mini App.
9. `user_manager_tool`: управление пользователями через команды чата.
10. `yt_dlp`: скачивание медиаконтента с YouTube и видеохостингов.\n
