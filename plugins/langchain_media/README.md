# LangChain Media Plugin

Плагин `langchain_media` обеспечивает интеллектуальный поиск медиа-контента (фильмов, сериалов, аниме) и торрентов в проекте Mediteka, используя LangChain, Model Context Protocol (MCP) и Playwright.

## Архитектура
- **LangChain**: Координирует процесс выполнения запросов и выбирает подходящие инструменты на основе намерений пользователя (найти плеер, найти информацию или торрент).
- **MCP (Model Context Protocol)**: Обеспечивает стандартизированный интерфейс между ИИ-моделями и локальными инструментами/скриптами.
- **Playwright**: Используется для скрапинга и автоматизации поиска на трекерах и в онлайн-кинотеатрах, обходя защиту и выполняя поиск в реальном времени.

## Интеграция с чат-системой
Плагин автоматически активируется, если запрос пользователя содержит определенные ключевые слова (например, "найди фильм", "где посмотреть", "скачать сериал"). Он перехватывает сообщение и запускает асинхронный поток (`search_stream`), отправляя пользователю статусы выполнения (например, "🔍 Запуск LangChain агента...") перед финальным результатом.

## Конфигурация
Настройки плагина берутся из файла `config.json` (раздел `langchain` и `media`). Чувствительные данные (пароли, токены) всегда хранятся в переменных окружения (`.env`), а не в коде.

## Доступные инструменты (Tools)
Агент может использовать различные инструменты:
- **Поиск торрентов**: Интеграция с `PlaywrightTorrentSearcher`.
- **Поиск источников**: Обращение к `sources.json` для онлайн-плееров (CosmicPlayer).
- **Сбор информации**: Получение рейтингов и описаний из открытых баз.

## Типы ответов
Плагин возвращает HTML-фрагменты, адаптированные для веб-интерфейса:
1. `player`: Карточка с кнопкой запуска видео через CosmicPlayer.
2. `torrent`: Список найденных торрентов с кнопками "Скачать", содержащими необходимые data-атрибуты для обработки фронтендом.
3. `info`: Информационная карточка фильма (год, рейтинг, описание).

## Зависимости
- LangChain
- Playwright
- Инфраструктура Mediteka (`BasePlugin`, `UnifiedChatModel`, `CosmicPlayer`)

## Пример использования
Пользователь: *"Где посмотреть сериал Укрытие?"*
Плагин распознает интент "где посмотреть", запускает агента, который ищет источники, и возвращает карточку с плеером HDRezka/Seasonvar, где можно запустить просмотр.
