# Чат Code Helper

Интерфейс для взаимодействия с RAG-индексом кодовой базы через модель Gemini.

## Предназначение
- Предоставление разработчикам возможности задавать вопросы по кодовой базе и получать контекстно-зависимые ответы, основанные на проиндексированных файлах проекта.

## Принцип работы
- `CodeHelperChat` инициализирует `FaissEngine` для поиска релевантного контекста.
- Запрос пользователя дополняется найденным контекстом и отправляется в модель Gemini для генерации ответа.
- Запуск: `python plugins/code_helper/rag/chat_interface.py`.
