# Управление актуализацией документации

## 🚀 Назначение
Этот навык автоматизирует проверку и синхронизацию документации с изменениями в программном коде.

## ⚙️ Основные правила
1. **Атомарность изменений:** Любые правки логики или структуры кода должны сопровождаться немедленным обновлением связанных документов (например, `README.md`, `schema.md`, `workflow.md`).
2. **Стандартизация:** Публичные методы и API должны снабжаться комментариями стандарта `hypo69 docblock`.

## 🛠️ Запуск инструмента
Для автоматической проверки или обновления документации используйте команду:
`python manage_tools.py docs update`
