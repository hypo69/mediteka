# Модуль `src` — Ядро системы (Core Layer)

## Назначение
Директория `src` содержит ключевые сервисные компоненты бэкенда приложения `mediteka`:
- Маршрутизация FastAPI и WebSocket (`src.fastapi`)
- Интеграция с моделями искусственного интеллекта (`src.ai`)
- Внешние сервисные клиенты (`src.clients`)
- Подсистема логирования (`src.logger`)
- Управление секретами и API-ключами (`src.secrets`)
- Движки синтеза речи TTS (`src.tts`)
- Управление профилями пользователей (`src.user_manager`)
- Набор вспомогательных утилит и конверторов (`src.utils`)\n
