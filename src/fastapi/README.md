# Модуль `src.fastapi` — Маршрутизация HTTP и WebSocket

## Назначение
Пакет предоставляет набор FastAPI APIRouter для обслуживания веб-интерфейсов и API-эндпоинтов:
- `router_chat.py`: WebSocket и SSE эндпоинты для интерактивного чата с AI-ассистентом.
- `router_media.py`: API доступа к медиатеке, потоковой трансляции, карточкам тайтлов и администрированию.
- `router_qbittorrent.py`: API управления торрент-клиентом (поиск, добавление, статус загрузок).
- `router_auth.py`: аутентификация через Google OAuth2, локальный вход и валидация JWT токенов.
- `router_control.py`: WebSocket шлюз дистанционного управления плеером (`/ws/control`).
- `router_tts.py`: синтез речи и выбор голосов для озвучки.
- `router_logs.py`: просмотр и анализ журналов событий.
- `router_keys.py`: проверка состояния и переключение API-ключей.
- `router_admin.py`: эндпоинты панели системного администратора.\n
