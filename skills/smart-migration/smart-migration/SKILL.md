# Smart Migration (Умный Перенос)

## 📋 Описание
Навык `smart-migration` предназначен для безопасного, структурированного и оптимизированного переноса сериалов/медиафайлов. В отличие от простого копирования, он сохраняет целостность медиатеки во всех связанных системах.

## ⚙️ Три шага умного переноса
1. **Физический перенос (Smart Copy):** Копирование файлов в новую папку назначения с оптимизацией (файлы с одинаковыми именами и размерами пропускаются, что экономит IO и время).
2. **Обновление путей в SQLite:** Точечный поиск записей сериала и всех вложенных сезонов/файлов в БД с заменой старого префикса пути на новый префикс. Это исключает коллизии уникальных ключей (`UNIQUE constraint failed: media.path`).
3. **Обновление локации в qBittorrent:** Поиск активной раздачи по имени папки в торрент-клиенте и обновление её пути загрузки.

## 🚀 Как запускать

- **Полный перенос (Копирование + БД + qBittorrent):**
  ```powershell
  python skills/smart-migration/smart-migration/scripts/perform_migration.py
  ```

- **Безопасный перенос (Только Копирование + БД, без торрент-клиента):**
  ```powershell
  python skills/smart-migration/smart-migration/scripts/perform_migration_safe.py
  ```

## 🛠️ Интерактивная обработка ошибок
Скрипты имеют встроенную систему подтверждения при возникновении сбоев:
* **`c` (continue)** — Пропустить текущий сериал (если возникла неустранимая ошибка) и перейти к следующему.
* **`r` (retry)** — Попробовать запустить процедуру переноса для этого сериала повторно (например, после того как была освобождена папка на диске или исправлена БД).
* **`s` (stop)** — Остановить миграцию полностью.
