# reports/ — Отчёты и артефакты анализа

Директория для хранения **автоматически генерируемых отчётов**: покрытие тестами, аудиты, результаты AI-анализа.

> Для отчётов по дискам медиатеки используй `media_reports/`.  
> Эта директория — для отчётов инструментов разработки и CI.

---

## Типичное содержимое

| Файл | Источник |
|------|---------|
| `coverage.xml` | `run_tests.ps1 -Coverage` |
| `audit_*.md` | `manage_tools.py audit` |
| `test_summary.md` | `run_tests.ps1` |

---

## Для агентов ИИ

При генерации отчётов сохраняй их здесь:
```python
REPORTS_DIR = Path(__root__) / "reports"
REPORTS_DIR.mkdir(exist_ok=True)
```
