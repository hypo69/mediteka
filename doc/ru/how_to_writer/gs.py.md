### Инструкции для генерации документации к коду

=========================================================================================

**Описание**
-------------------------
Этот блок кода загружает параметры программы из файла `config.json` с использованием функции `j_loads_ns` и сохраняет их в переменную `gs`. Этот модуль предназначен для загрузки и хранения глобальных настроек приложения.

**Шаги выполнения**
-------------------------
1.  Импортируются необходимые модули: `header` (предположительно, для общих настроек), `j_loads_ns` из `src.utils.jjson` для загрузки JSON, и `Path` из `pathlib` для работы с путями к файлам.
2.  Создается объект `Path` для файла `config.json`.
3.  Функция `j_loads_ns` вызывается с путем к файлу `config.json` для загрузки JSON данных.
4.  Загруженные данные присваиваются переменной `gs`, которая, как предполагается, используется в других частях программы как хранилище глобальных настроек.

**Пример использования**
-------------------------
```python
from pathlib import Path
from src.utils.jjson import j_loads_ns

# Предполагается, что файл config.json существует в том же каталоге
config_path = Path('config.json')

# Загружаем параметры из config.json
gs = j_loads_ns(config_path)

# Теперь переменная gs содержит загруженные параметры, например:
# print(gs)
```
