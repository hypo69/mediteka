    -   Добавлены дополнительные сведения о логировании, истории чата и обработке ошибок.
    -   Указаны важные замечания по использованию и настройке.
    -   Добавлены лицензионное соглашение и информация об авторе.

4. **Описание методов:**
     -   `__init__` - Инициализирует объект `GoogleGenerativeAI` с API-ключом, именем модели, настройками генерации и системной инструкцией.
     -   `ask` - Отправляет текстовый запрос к модели и возвращает ответ.
     -   `chat` - Отправляет запрос в чат, сохраняя историю диалога.
     -   `describe_image` - Отправляет изображение в Gemini Pro Vision для текстового описания.
     -   `upload_file` - Загружает файл в Gemini API.

**Пример использования**
-------------------------
```python
# Инициализация класса
from src.ai.gemini.generative_ai import GoogleGenerativeAI
import gs

system_instruction = "Ты - полезный ассистент. Отвечай на все вопросы кратко"
ai = GoogleGenerativeAI(api_key=gs.credentials.gemini.api_key, system_instruction=system_instruction)

# Пример использования метода ask
async def example_ask():
    response = await ai.ask("Что такое Python?")
    if response:
        print(f"Ответ модели: {response}")
    else:
       print("Не удалось получить ответ.")

# Пример использования метода chat
async def example_chat():
    while True:
        user_message = input("Вы: ")
        if user_message.lower() == 'exit':
            break
        ai_message = await ai.chat(user_message)
        if ai_message:
             print(f"Gemini: {ai_message}")
        else:
             print("Gemini: Ошибка получения ответа")

# Пример использования метода describe_image
async def example_describe_image():
    image_path = Path("test.jpg")
    prompt = "Опиши это изображение."
    description = await ai.describe_image(image_path, prompt=prompt)
    if description:
        print(f"Описание изображения: {description}")
    else:
        print("Не удалось получить описание изображения.")

# Пример использования метода upload_file
async def example_upload_file():
    file_path = Path("test.txt")
    with open(file_path, "w") as f:
        f.write("Это тестовый файл.")
    upload_result = await ai.upload_file(file_path, "test_file.txt")
    if upload_result:
         print("Файл успешно загружен.")
    else:
        print("Не удалось загрузить файл.")

# Запуск примеров
async def main():
    await example_ask()
    await example_chat()
    await example_describe_image()
    await example_upload_file()
    
import asyncio
if __name__ == "__main__":
    asyncio.run(main())
```
