### Инструкции для генерации документации к коду

=========================================================================================

**Описание**
-------------------------
Этот JSON-документ описывает структуру запроса к API Google Gemini для генерации контента. Он включает различные параметры и поля, позволяющие настроить запрос для получения желаемого результата. Структура включает кэшированный контент, контентные части, системные инструкции, инструменты, настройки безопасности, настройки генерации, метки и др.

**Шаги выполнения**
-------------------------
1.  **Разбор структуры JSON**:
    -   `cachedContent`: Строка, представляющая кэшированный контент (если есть).
    -   `contents`: Массив объектов контента.
        -   `role`: Роль контента (например, "user", "model").
        -   `parts`: Массив частей контента. Может содержать:
            -   `text`: Текстовая часть.
            -   `inlineData`: Встроенные данные (например, изображение).
                -   `mimeType`: MIME-тип данных.
                -   `data`: Данные, закодированные в base64.
            -   `fileData`: Ссылка на файл.
                -  `mimeType`: MIME-тип файла.
                -  `fileUri`: URI файла.
            -   `videoMetadata`: метаданные для видео.
                - `startOffset`: Время начала видео.
                -   `endOffset`: Время окончания видео.
    -   `systemInstruction`: Объект с системными инструкциями.
        -   `role`: Роль инструкции (например, "user").
        -   `parts`: Массив частей инструкции, обычно содержит текст.
    -   `tools`: Массив объектов инструментов.
        -   `functionDeclarations`: Массив объявлений функций.
            -   `name`: Имя функции.
            -   `description`: Описание функции.
            -   `parameters`: Параметры функции (обычно объект).
    -   `safetySettings`: Массив настроек безопасности.
        -   `category`: Категория безопасности (например, "HARM_CATEGORY_SEXUALLY_EXPLICIT").
        -   `threshold`: Порог блокировки (например, "BLOCK_LOW_AND_ABOVE").
    -   `generationConfig`: Настройки генерации.
        -   `temperature`: Температура генерации.
        -   `topP`: Вероятность top-p.
        -   `topK`: Количество top-k.
        -   `candidateCount`: Количество кандидатов.
        -   `maxOutputTokens`: Максимальное количество токенов вывода.
        -    `presencePenalty`: Штраф за присутствие.
        -    `frequencyPenalty`: Штраф за частоту.
        -   `stopSequences`: Массив последовательностей для остановки генерации.
        -   `responseMimeType`: MIME-тип ответа.
        -   `responseSchema`: Схема ответа.
        -  `seed`: Случайное зерно.
        -   `responseLogprobs`: Флаг для лог-вероятностей ответа.
        -   `logprobs`: Количество лог-вероятностей.
        -   `audioTimestamp`: Флаг для меток времени аудио.
    -   `labels`: Объект с метками (ключ-значение).
2.  **Общее описание:**
    -   Этот JSON определяет структуру запроса к Google Gemini API для генерации текста, изображений или файлов, с учетом ролей, инструкций, настроек безопасности и генерации, а также инструментов.
3.  **Использование:**
    -   Этот JSON можно использовать для создания запросов к API Google Gemini. Параметры могут быть настроены в соответствии с требованиями задачи.
    -   Каждое поле имеет определенную цель и может быть настроено для управления поведением модели.

**Пример использования**
-------------------------
```python
import json

# Пример JSON-запроса
request_data = {
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "text": "Напиши краткое введение о Python."
        }
      ]
    }
  ],
  "generationConfig": {
    "temperature": 0.7,
    "maxOutputTokens": 256,
    "responseMimeType": "text/plain"
  }
}

# Преобразование Python-словаря в JSON-строку
json_request = json.dumps(request_data, indent=2)

print(json_request)
```
