# Модуль `src.header`

## Обзор

Модуль `src.header` определяет корневой путь к проекту. Все импорты строятся относительно этого пути.

## Оглавление

1.  [Обзор](#обзор)
2.  [Импорты](#импорты)
3.  [Функции](#функции)
    -   [`set_project_root`](#set_project_root)
4.  [Глобальные переменные](#глобальные-переменные)
    -   [`__root__`](#__root__)

## Импорты

Модуль использует следующие импорты:

-   `sys`: Модуль для работы с параметрами и функциями, специфичными для системы.
-   `Path` из `pathlib`: Класс для работы с путями файлов.

## Функции

### `set_project_root`

```python
def set_project_root(marker_files: tuple = ('__root__','.git')) -> Path:
    """
    Finds the root directory of the project starting from the current file's directory,
    searching upwards and stopping at the first directory containing any of the marker files.

    Args:
        marker_files (tuple): Filenames or directory names to identify the project root.
    
    Returns:
        Path: Path to the root directory if found, otherwise the directory where the script is located.
    """
```

**Описание**:
Функция `set_project_root` находит корневой каталог проекта, начиная с каталога текущего файла, ища вверх и останавливаясь в первом каталоге, содержащем любой из файлов-маркеров.

**Параметры**:

-   `marker_files` (tuple, optional): Кортеж имен файлов или каталогов для идентификации корня проекта. По умолчанию `('__root__', '.git')`.

**Возвращает**:

-   `Path`: Путь к корневому каталогу, если он найден, в противном случае - каталог, где расположен скрипт.

## Глобальные переменные

### `__root__`

**Описание**:
Глобальная переменная `__root__` содержит путь к корневому каталогу проекта, который устанавливается при вызове функции `set_project_root`.

**Тип**:
`pathlib.Path`

**Пример использования**:
```python
import sys
from pathlib import Path

def set_project_root(marker_files: tuple = ('__root__','.git')) -> Path:
    """
    Finds the root directory of the project starting from the current file's directory,
    searching upwards and stopping at the first directory containing any of the marker files.

    Args:
        marker_files (tuple): Filenames or directory names to identify the project root.
    
    Returns:
        Path: Path to the root directory if found, otherwise the directory where the script is located.
    """
    __root__:Path
    current_path:Path = Path(__file__).resolve().parent
    __root__ = current_path
    for parent in [current_path] + list(current_path.parents):
        if any((parent / marker).exists() for marker in marker_files):
            __root__ = parent
            break
    if __root__ not in sys.path:
        sys.path.insert(0, str(__root__))
    return __root__
__root__: Path = set_project_root()
print(__root__)
# Path to the root directory of the project

**Возвращает**:
