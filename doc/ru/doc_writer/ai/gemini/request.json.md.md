# Документация по формату JSON для Google Gemini API

## Обзор

Данная документация описывает структуру JSON, используемую для запросов к Google Gemini API. Этот формат включает в себя различные параметры, такие как кэшированный контент, содержимое сообщений, системные инструкции, инструменты, настройки безопасности и конфигурации генерации.

## Структура JSON

### `cachedContent`

**Описание**:
Строка, содержащая кэшированный контент.

**Тип**:
`string`

### `contents`

**Описание**:
Массив объектов, представляющих сообщения.

**Тип**:
`array` of `object`

**Структура объекта `contents`**:

-   `role`: `string` - роль отправителя сообщения (например, "user" или "model").
-   `parts`: `array` of `object` - массив объектов, содержащих различные части сообщения.

    **Структура объекта `parts`**:

    -   `text`: `string` - текстовая часть сообщения.
    -   `inlineData`: `object` - объект, содержащий встроенные данные.
        -   `mimeType`: `string` - MIME-тип данных.
        -   `data`: `string` - данные, закодированные в Base64.
    -  `fileData`: `object` - объект, содержащий данные о файле.
       -   `mimeType`: `string` - MIME-тип файла.
       -   `fileUri`: `string` - URI файла.
    -   `videoMetadata`: `object` - метаданные для видео.
        -   `startOffset`: `object` - начальное смещение видео.
            -   `seconds`: `integer` - секунды.
            -   `nanos`: `integer` - наносекунды.
        -   `endOffset`: `object` - конечное смещение видео.
            -   `seconds`: `integer` - секунды.
            -   `nanos`: `integer` - наносекунды.

### `systemInstruction`

**Описание**:
Объект, содержащий системные инструкции.

**Тип**:
`object`

**Структура объекта `systemInstruction`**:

-   `role`: `string` - роль инструкции (например, "system").
-   `parts`: `array` of `object` - массив объектов, содержащих текст инструкции.

    **Структура объекта `parts`**:
    -   `text`: `string` - текстовая часть инструкции.

### `tools`

**Описание**:
Массив объектов, описывающих инструменты.

**Тип**:
`array` of `object`

**Структура объекта `tools`**:

-   `functionDeclarations`: `array` of `object` - массив объявлений функций.
    -   `name`: `string` - имя функции.
    -   `description`: `string` - описание функции.
    -   `parameters`: `object` - параметры функции.

### `safetySettings`

**Описание**:
Массив объектов с настройками безопасности.

**Тип**:
`array` of `object`

**Структура объекта `safetySettings`**:

-   `category`: `enum` - категория (HarmCategory).
-   `threshold`: `enum` - порог (HarmBlockThreshold).

### `generationConfig`

**Описание**:
Объект с конфигурацией генерации.

**Тип**:
`object`

**Структура объекта `generationConfig`**:

-   `temperature`: `number` - температура.
-   `topP`: `number` - top P.
-   `topK`: `number` - top K.
-   `candidateCount`: `integer` - количество кандидатов.
-   `maxOutputTokens`: `integer` - максимальное количество токенов.
-   `presencePenalty`: `float` - штраф за присутствие.
-   `frequencyPenalty`: `float` - штраф за частоту.
-   `stopSequences`: `array` of `string` - последовательности остановки.
-   `responseMimeType`: `string` - MIME-тип ответа.
-   `responseSchema`: `schema` - схема ответа.
-   `seed`: `integer` - seed.
-   `responseLogprobs`: `boolean` - лог-вероятности для ответа.
-   `logprobs`: `integer` - количество лог-вероятностей.
-   `audioTimestamp`: `boolean` - отметка времени аудио.

### `labels`

**Описание**:
Словарь меток.

**Тип**:
`object`

**Структура объекта `labels`**:

-   `string` : `string` - пара ключ-значение.
