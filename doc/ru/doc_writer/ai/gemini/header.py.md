## Импорты

Модуль использует следующие импорты:

-   `sys`: Модуль для работы с параметрами и функциями, специфичными для системы.
-   `json`: Модуль для работы с JSON.
-    `Version` из `packaging.version`: Класс для работы с версиями.
-   `Path` из `pathlib`: Класс для работы с путями файлов.
-  `gs` из `src`: Глобальные настройки приложения.

## Функции

### `set_project_root`

```python
def set_project_root(marker_files: tuple = ('__root__','.git')) -> Path:
    """
    Finds the root directory of the project starting from the current file's directory,
    searching upwards and stopping at the first directory containing any of the marker files.

    Args:
        marker_files (tuple): Filenames or directory names to identify the project root.
    
    Returns:
        Path: Path to the root directory if found, otherwise the directory where the script is located.
    """
```

**Описание**:
Функция `set_project_root` находит корневой каталог проекта, начиная с каталога текущего файла, ища вверх и останавливаясь в первом каталоге, содержащем любой из файлов-маркеров.

**Параметры**:

-   `marker_files` (tuple, optional): Кортеж имен файлов или каталогов для идентификации корня проекта. По умолчанию `('__root__', '.git')`.

**Возвращает**:

-   `Path`: Путь к корневому каталогу, если он найден, в противном случае - каталог, где расположен скрипт.

**Описание**:

**Тип**:
`pathlib.Path`

**Описание**:

**Тип**:

**Описание**:
