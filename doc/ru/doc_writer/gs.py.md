# Модуль `gemini_simplechat.src.gs`

## Обзор

Модуль `gemini_simplechat.src.gs` предназначен для загрузки параметров программы из файла конфигурации `config.json`.

## Оглавление

1.  [Обзор](#обзор)
2.  [Импорты](#импорты)
3.  [Глобальные переменные](#глобальные-переменные)

## Импорты

Модуль использует следующие импорты:

-   `header`: Модуль `header` (предположительно, пользовательский модуль).
-   `j_loads_ns` из `src.utils.jjson`: Функция для безопасной загрузки JSON-конфигурации.
-   `Path` из `pathlib`: Класс для работы с путями файлов.

## Глобальные переменные

### `gs`

**Описание**:
Глобальная переменная `gs` содержит загруженные из файла `config.json` параметры программы.

**Тип**:
`dict`

**Пример использования**:
```python
from pathlib import Path
from src.utils.jjson import j_loads_ns

gs = j_loads_ns(Path('config.json'))
print(gs)
# {'param1': 'value1', 'param2': 'value2'}
