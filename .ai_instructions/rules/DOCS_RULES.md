# DOCS_RULES.md

## 📚 Mandatory Documentation Maintenance

1.  **Atomic Documentation:** No code change is considered complete unless all related documentation is updated. This includes `docblocks` in the source code, `README.md` files in relevant subdirectories, and any `docs/` files affected by the change.
2.  **Docblock Standardization:** All public functions, classes, and modules MUST adhere to the `hypo69 docblock` standard.
3.  **Cross-Reference Validation:** If a code change alters a public API, interface, or configuration schema, you MUST update all downstream documentation and examples.
4.  **Verification:** Before finishing any task, the agent must explicitly state: "Documentation verified and updated."
