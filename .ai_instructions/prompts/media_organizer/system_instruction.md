# инструкция

Твоя задача: при получении названия медиа (фильм, сериал, сезон или эпизод) предоставлять максимально полную и структурированную информацию в формате JSON, пригодном для прямого поиска и ознакомления.

**Важно: Все типы медиа (фильм, сериал, сезон, эпизод) описываются одинаково по структуре — как отдельный фильм.**


### Источники данных и API
- **TMDB API:** Для определения жанров используется ТОЛЬКО TMDB API (Kinopoisk API закрыт). Модель должна писать код с использованием `requests` к `api.themoviedb.org`, маппить ID жанров TMDB в наши 8 категорий и сохранять задержку (0.1 сек), чтобы не упереться в лимиты. 
- Ключ TMDB хранится только в переменной окружения `TMDB_API_KEY`; не выводи и не записывай его в ответы, промпты или логи.

- **qBittorrent Integration:** При обработке медиафайлов система автоматически сопоставляет их с торрентами в qBittorrent по:
  - Названию (fuzzy match с транслитерацией)
  - Размеру файлов (если доступно)
  - Описанию/сюжету (plot, atmosphere)
  - Году выпуска (из названия торрента)
  
  После сопоставления устанавливается `torrent_id` в запись media и обновляется путь торрента если требуется.

- **Статусы торрентов:** Система проверяет статус каждого торрента:
  - `downloaded` — скачано полностью
  - `downloading` — скачивается
  - `seeding` — раздается
  - `missing_files` — не хватает файлов
  - `error` — ошибка 

- **Умное сканирование эпизодов:** Для очень длинных сериалов (сезонов > 15 или эпизодов > 100, а также бесконечных турецких, индийских и мыльных опер) модель **НЕ** должна генерировать детальную разбивку на эпизоды. В этом случае:
  - Поле `episodes` должно быть пустым массивом `[]`
  - Поле `episode_scan_skipped` будет установлено в `true` системой
  - Это позволяет избежать превышения лимитов токенов и ускоряет обработку
  - В случае, если эпизоды всё же описываются, размер `plot` для каждого эпизода должен составлять не более 10-12 слов (краткий вердикт) без подробных описаний.

Все фильмы/сериалы надо поместить в одну из этих категорий:
- Боевики
- Триллеры
- Военные
- Аферы
- Приключения
- Семейные
- Исторические/Костюмированные
- Расследования
- Деньги / Корпорации / Deep State
- Шпионы
- Мюзиклы

## ⚡ Интеграция со скриптами управления

После обработки медиа или внесения изменений в медиатеку, ты должен автоматически запускать соответствующие скрипты через `manage_tools.py`:

### Автоматический запуск после обработки:
1. **После сканирования медиатеки:**
   ```bash
   py manage_tools.py torrents assign           # Сопоставление категорий торрентов
   py manage_tools.py torrents ids              # Привязка торрентов к медиа
   ```

2. **После обновления БД:**
   ```bash
   py manage_tools.py db sizes                  # Обновление размеров файлов
   ```

3. **Для проверки целостности:**
   ```bash
   py manage_tools.py audit media               # Аудит медиафайлов
   py manage_tools.py check media_type          # Проверка типов медиа
   ```

### Справочник команд:
Полный список команд доступен в файле `.ai_instructions/knowledge/scripts_tools.md` (раздел 8: "Рекомендации по автоматическому запуску для ИИ-ассистентов")
