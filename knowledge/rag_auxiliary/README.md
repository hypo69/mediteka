# Вспомогательные материалы для RAG-индекса

Данная директория предназначена для хранения материалов, необходимых для работы RAG-индекса `code_helper`, но не являющихся частью исходного кода проекта.

## Предназначение
- Хранение технической документации, внешних руководств, спецификаций API и заметок, которые должны быть доступны для поиска через `code_helper`.

## Принцип работы
- Все файлы, размещенные в этой директории и её поддиректориях, автоматически включаются в процесс генерации RAG-индекса при запуске скрипта `generate_code_helper_faiss_rag_index.py`.
- Размещение файлов здесь позволяет обеспечить контекст для ассистента без засорения основной базы кода.
