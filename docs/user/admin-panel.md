# Админ-панель

Админ-панель позволяет управлять медиатекой, настраивать плагины и контролировать систему.

## Доступ

Откройте админ-панель:

```
http://localhost:3000/admin
```

## Секции админки

### 1. Медиатека

#### Сканирование дисков

1. Выберите диск (например, "ДИСК 1")
2. Выберите пути для сканирования
3. Нажмите "Начать сканирование"

Опции:
- **Глубокое сканирование** — с анализом каждого файла
- **Классификация через AI** — определение жанров и категорий
- **Обновление TMDB** — получение актуальных данных

#### Аудит медиатеки

1. Выберите диск
2. Нажмите "Провести аудит"

Проверки:
- Отсутствие файлов на диске
- Неполные серии
- Дубликаты
- Отсутствие метаданных

### 2. Torrents

#### Управление qBittorrent

- **Список торрентов** — текущие загрузки
- **Добавить торрент** — по magnet-ссылке или файлу
- **Удалить торрент** — с опцией удаления файлов
- **Переместить** — изменение сохранённого пути
- **Перепроверка** — проверка целостности

#### Категории

- **Назначить категории** — автоматически по БД
- **Управление категориями** — создание и редактирование

### 3. Плагины

#### Управление плагинами

| Плагин | Статус | Действия |
|--------|--------|----------|
| media_organizer | Активен | Настройки |
| qbittorrent | Активен | Настройки |
| rag | Активен | Перестроить индекс |
| telegram_bot | Активен | Перезапустить |

### 4. RAG Поиск

#### Построение индекса

1. Выберите API ключ
2. Нажмите "Построить индекс"

Опции:
- **Полное построение** — пересоздать весь индекс
- **Инкрементальное** — обновить изменения

#### Поиск

```markdown
# Примеры запросов
"Фильмы про войну"
"Сериалы с Карпушенко"
"Триллеры 2020-2025"
```

### 5. Пользователи

#### Управление пользователями

- **Список пользователей** — email, роль, дата регистрации
- **Сброс пароля** — для пользователей JWT
- **Удаление** — удаление аккаунта

### 6. Настройки системы

#### Конфигурация

| Параметр | Значение |
|----------|----------|
| Port | 3000 |
| Host | 0.0.0.0 |
| SSL | Включено/Выключено |
| Telegram Bot | Активен |

#### Медиа настройки

- **Каталоги по умолчанию** — пути для сканирования
- **Категории** — список доступных категорий
- **Настройки TTS** — голоса и параметры

## Статистика

### Общая информация

- **Всего медиафайлов** — количество записей в БД
- **Общий размер** — занятое место
- **Количество категорий** — число жанров
- **Активных торрентов** — количество загрузок

### Системные метрики

- **Загрузка CPU** — процент использования
- **Использование памяти** — объем памяти
- **Сеть** — исходящий/входящий трафик

## Экспорт данных

### Выгрузка отчётов

- **Excel** — для анализа в Excel
- **JSON** — для программной обработки
- **Markdown** — для документации

### Резервное копирование

1. Нажмите "Создать резервную копию"
2. Файл сохранится в `backups/`

## Устранение проблем

### База данных

- **Консолидация дублей** — объединение дублирующихся записей
- **Перестроение БД** — полное восстановление

### Кэш

- **Очистка кэша** — удаление временных файлов
- **Сброс индекса** — пересоздание RAG-индекса
