# ai-mediteka Documentation

Welcome to the ai-mediteka documentation. This site is built with MkDocs and the Material theme.

Use the navigation on the left to browse the user guide, developer guide, integrations and troubleshooting.

To build the documentation locally:

```bash
pip install mkdocs mkdocs-material mkdocstrings
mkdocs build
mkdocs serve  # to preview locally
```

The generated site will be available in the `site/` directory after building.
