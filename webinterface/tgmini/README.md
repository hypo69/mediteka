# Интеграция Telegram Mini App (/tgmini)

Модуль интеграции с Telegram WebApp SDK, содержащий клиент чата с AI-моделью и полноценный пульт ДУ плеера.

## Структура файлов
* `index.html` — шаблон интерфейса с вкладками «Локальный плеер», «Чат» и «Пульт ДУ».
* `main.js` — инициализация Telegram Web Apps SDK, темы оформления, WebSocket-соединения с бэкендом, логика Haptic Feedback и голосового управления.
* `style.css` — стили, адаптированные под CSS переменные тем оформления клиента Telegram.

## Дополнительные фичи для Telegram

### 1. Telegram WebApp Haptic Feedback
При каждом нажатии кнопок на пульте или активации микрофона вызывается тактильный виброотклик смартфона:
```javascript
window.api.tg.hapticFeedback({ impactStyle: 'light' });
```

### 2. Поддержка тем Telegram
Цветовая схема пульта автоматически адаптируется под темную или светлую тему мессенджера пользователя благодаря отслеживанию события `themeChanged` и чтению `tg.themeParams`.
