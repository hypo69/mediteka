# Вкладка `search_tab` — Управление провайдерами веб-поиска (MCP)

## Описание
Данный модуль предоставляет интерфейс администратора для настройки и тестирования серверов и провайдеров веб-поиска:
- **🎭 Playwright MCP**: Браузерный поиск через headless Chromium.
- **🦜 LangChain MCP**: Автономный ReAct-агент медиа-поиска.
- **♊ Google Gemini Grounding**: Поиск через `google-genai` SDK с ротацией ключей.
- **🚀 Antigravity (AGY)**: Агентный веб-поиск Google Antigravity.

## Файлы:
- `index.html` — разметка вкладки веб-поиска и тестовой формы.
- `main.js` — клиентская логика загрузки, сохранения конфигурации и интерактивного тестирования поиска.
