# Модуль `webinterface/rag_tab` — Панель управления RAG

## Назначение
Интерфейс мониторинга состояния векторных индексов, запуска переиндексации, загрузки внешних документов и тестирования точности семантического поиска.

## Источники данных и функционал

### 1. Медиа-RAG (`type=media`)
- **Кнопка «Построить индекс»:** Запускает переиндексацию таблицы `media` из SQLite-базы `plugins/media_organizer/data/media.db`.
- **Принцип работы:** Экспортирует уже сохраненные и классифицированные записи (`title`, `plot`, `genres`, `cast`, `facts` и т.д.), компилирует их в текстовые фрагменты и строит векторный индекс через модель эмбеддингов в `media_rag.db`. Файлы на физических дисках повторно не сканируются.
- **Кнопка «➕ JSON»:** Позволяет загружать произвольные `.json`, `.txt`, `.md` документы или сканировать серверную директорию (например, `C:\mediteka\RAGDATA`) напрямую в векторную базу без изменения `media.db`.

### 2. Чат-RAG (`type=chat`)
- **Кнопка «Построить индекс»:** Индексирует сохраненную историю диалогов и ответов ассистента из файлового хранилища `data/store/responses`.
- Служит долгосрочной памятью диалогов для чат-модели.

## Файлы модуля
- `index.html` — разметка вкладки (селекторы режима, блок справки, поисковая панель, инспектор документов).
- `main.js` — клиентская логика взаимодействия с REST API (`/api/media-admin/rag/*`).
