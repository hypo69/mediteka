# Связи актёров за пределами «Сватов»

Особый интерес для поиска представляют проекты, в которых актёры «Сватов» встречались друг с другом вне основного сериала.

Такие связи позволяют строить дополнительные ассоциации.

Например, пользователь может помнить актёра по одной роли и не знать его имени.

Поиск через фильмографию позволяет связать этот проект со «Сватами».

Такой тип связи особенно полезен для RAG.

# Как использовать этот блок в RAG

Для каждого актёра желательно создавать несколько связей.

Актёр связан с персонажем.

Персонаж связан с сериалом.

Актёр связан с фильмами.

Актёр связан с другими сериалами.

Актёр связан с другими актёрами.

Актёр связан с жанрами.

Такой граф позволяет отвечать на разные типы вопросов.

Например, пользователь может спросить, кто играл Ивана Будько.

Затем он может спросить, где ещё снимался этот актёр.

После этого он может спросить, в каких проектах снимались вместе актёры «Сватов».

Все эти вопросы должны находить ответ через один и тот же индекс.

# Главная особенность актёрского состава

Успех «Сватов» во многом связан с тем, что персонажи воспринимаются как самостоятельные личности.

Зритель запоминает не только актёров.

Он запоминает характеры.

Иван ассоциируется с непосредственностью.

Валентина с эмоциональностью.

Ольга с контролем.

Юрий со спокойствием.

Митяй с невероятными историями.

Женя с взрослением.

Поэтому фильмография актёров особенно полезна тогда, когда связывает реальные роли с узнаваемыми экранными образами.
