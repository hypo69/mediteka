    Админ-панель

    Админ-панель позволяет управлять медиатекой, настраивать плагины, управлять системными инструкциями и контролировать систему.

    Доступ

    Откройте админ-панель:

    http://localhost:3000/admin

    Секции админки

    1. Медиатека

    Сканирование дисков

    1. Выберите диск (например, "ДИСК 1")
    2. Выберите пути для сканирования
    3. Нажмите "Начать сканирование"

    Опции: - Глубокое сканирование — с анализом каждого файла - Классификация через AI — определение жанров и категорий - Обновление TMDB — получение актуальных данных

    Аудит медиатеки

    1. Выберите диск
    2. Нажмите "Провести аудит"

    Проверки: - Отсутствие файлов на диске - Неполные серии - Дубликаты - Отсутствие метаданных

    2. Системные инструкции (AI Prompt Engineering)

    Панель управления системными инструкциями позволяет настраивать поведение ИИ для разных ролей (чат, рассказчик).

    • Редактирование активной инструкции: прямое редактирование system_instruction.md.
    • Версионирование: сохранение, активация и откат к предыдущим версиям инструкций в БД.
    • Тестирование: инструмент "Проверка инструкции" позволяет отправить тестовый промпт модели с текущей инструкцией для оценки результата и расхода токенов.

    3. Торренты

    Управление qBittorrent

    • Список торрентов — текущие загрузки
    • Добавить торрент — по magnet-ссылке или файлу
    • Удалить торрент — с опцией удаления файлов
    • Переместить — изменение сохранённого пути
    • Перепроверка — проверка целостности

    Категории

    • Назначить категории — автоматически по БД
    • Управление категориями — создание и редактирование

    4. Плагины

    Управление плагинами

    • Включение/выключение плагинов.
    • Настройки плагинов (если применимо).

    5. RAG Поиск

    Построение индекса

    1. Выберите API ключ
    2. Нажмите "Построить индекс"

    Опции: - Полное построение — пересоздать весь индекс - Инкрементальное — обновить изменения

    Поиск

    Проверка семантического поиска по медиатеке.

    6. Пользователи

    Управление пользователями

    • Список пользователей — email, роль, дата регистрации
    • Сброс пароля — для пользователей JWT
    • Удаление — удаление аккаунта

    7. Источники медиа

    Управление списком источников

    Прямое редактирование sources.json, используемого для поиска источников медиа (кинотеатры, iframe-плееры).

    8. Настройки системы

    Конфигурация

    Параметр Значение
    Port 3000
    Host 0.0.0.0
    SSL Включено/Выключено
    Telegram Bot Активен

    Медиа настройки

    • Каталоги по умолчанию — пути для сканирования
    • Категории — список доступных категорий
    • Настройки TTS — голоса и параметры

    Статистика

    Общая информация

    • Всего медиафайлов — количество записей в БД
    • Общий размер — занятое место
    • Количество категорий — число жанров
    • Активных торрентов — количество загрузок

    Системные метрики

    • Загрузка CPU — процент использования
    • Использование памяти — объем памяти
    • Сеть — исходящий/входящий трафик

    Экспорт данных

    Выгрузка отчётов

    • Excel — для анализа в Excel
    • JSON — для программной обработки
    • Markdown — для документации

    Резервное копирование

    1. Нажмите "Создать резервную копию"
    2. Файл сохранится в backups/

    Устранение проблем

    База данных

    • Консолидация дублей — объединение дублирующихся записей
    • Перестроение БД — полное восстановление

    Кэш

    • Очистка кэша — удаление временных файлов
    • Сброс индекса — пересоздание RAG-индекса
