## Возможности

- 🤖 **AI-ассистент** — Google Gemini для чатов и рекомендаций
- 🎬 **Умный медиаплеер** — воспроизведение с синхронизацией между устройствами
- 📡 **Пульт ДУ** — голосовое управление через Speech-to-Text и Text-to-Speech
- 📱 **Telegram Mini App** — удалённое управление из Telegram
- 📁 **Управление торрентами** — интеграция с qBittorrent
- 🧠 **RAG поиск** — векторный поиск по медиатеке
- 🧩 **Плагины** — расширяемая архитектура

## 🤖 Чат и Потоковый RAG-поиск (Streaming)

В чате реализован полностью потоковый вывод (Streaming) ответов ИИ и промежуточных шагов выполнения инструментов:
- **Эксклюзивный RAG-маршрут:** Запросы, классифицированные как относящиеся к поиску медиа, направляются **строго** в `RAGPlugin`. Это гарантирует использование контекста локальной базы данных (`media.db`) и исключает прямые запросы к модели без знаний о вашей медиатеке.
- **Интерактивные статусы:** Во время выполнения цепочки инструментов (Function Calling) бэкенд транслирует статус выполнения прямо в интерфейс через Server-Sent Events (SSE), например: `⚙️ Вызов функции search_media(...)`.
- **Финальный стриминг:** Найденные фильмы RAG-плагин встраивает в контекст модели, после чего рекомендация мгновенно печатается на экране.
- **Интерактивные карточки фильмов:** Если модель возвращает структурированную карточку фильма/сериала (в формате JSON), интерфейсы (и веб-плеер, и пульт ДУ) автоматически парсят её и отрисовывают как премиальный виджет с рейтингами (IMDb, Кинопоиск), описанием, жанрами и интерактивной кнопкой **«Запустить фильм»** для мгновенного воспроизведения.
- **Голосовой ассистент (TTS):** Пульт ДУ озвучивает найденные рекомендации голосом через Web Speech API, отфильтровывая JSON-теги и зачитывая только текстовое резюме.

## Быстрый старт

### Требования

- Python 3.10+
- Google Gemini API Key
- Node.js 18+ (для MCP сервера, опционально)

### Установка

```bash
# Клонирование репозитория
git clone https://github.com/hypo69/mediteka.git
cd mediteka

# Установка зависимостей
pip install -r requirements.txt

# Настройка переменных окружения
cp .env.example .env
# Отредактируйте .env файл

# Запуск сервера
python main.py
```

### Доступные интерфейсы

| Интерфейс | URL | Описание |
|-----------|-----|----------|
| Плеер | `/user` | Основной плеер с чатом AI |
| Пульт ДУ | `/rc` | Управление голосом + TTS |
| Telegram | `/tgmini` | Telegram Mini App |
| Админка | `/admin` | Управление медиатекой |

## Технологический стек

- **Backend**: Python 3.10+, FastAPI, Uvicorn

- **Database**: SQLite, JSON storage
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Media**: qBittorrent, TMDB API
